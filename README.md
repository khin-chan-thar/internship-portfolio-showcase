# Hotel Management System

## Internship Project

A web-based Hotel Management System developed as part of my internship experience. The system was built using Laravel and MySQL and includes hotel reservation, promotion management, reporting, and invoice generation features.

## My Role

During my internship, I contributed to the development and enhancement of the Hotel Management System, mainly focusing on promotion management, reservation promotion logic, reporting, and invoice generation, searching logic.

## My Contributions

- Promotion Management
  - Catalog Rule (Website Promotion)CRUD
  - Cart Rule (Corporate Promotion)CRUD

- Reservation Promotion & Pricing Logic
  - Promotion condition checking
  - Promotion retrieval from database
  - Promotion calculation
  - Double discount prevention

- Promotion UI
  - Available Promotions
  - Coming Soon Promotions
  - Promotion information in reservation form

- Birthday & Refund Logic
  - Birthday promotion eligibility
  - Refund amount calculation

- Reporting & Analytics
  - Promotion Report
  - Promotion Performance Report
  - Search and Filter functionality
  - Promotion eligibility checking in search page


- Invoice
  - Invoice PDF generation and design
